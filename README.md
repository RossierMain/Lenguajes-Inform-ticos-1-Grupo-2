# 🌲 Página Oficial de Gravity Falls

Sitio web institucional y turístico de la ciudad de Springfield (inspirado en *Los Simpson*), desarrollado para el Segundo Parcial de **Lenguajes Informáticos I**. 

La página web cuenta con 5 páginas navegables `index`,`lugares`,`ciudad`,`contactos` y `misterios`. Usando bootstrap incluimos carrousels y badgets. Con js incluimos el buscador de opiniones, modo oscuro y acordeon.
